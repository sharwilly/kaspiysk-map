# Карта проблем Каспийска

Веб-приложение, позволяющее жителям отмечать проблемы на интерактивной карте города.

## Цель версии 0.1

Любой пользователь может:

- поставить отметку на карте;
- выбрать категорию;
- добавить описание;
- прикрепить фотографию.

Любой пользователь может просматривать все обращения.

Без регистрации.
