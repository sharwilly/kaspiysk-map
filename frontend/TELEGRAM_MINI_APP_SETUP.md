# Подключение «Открытого Каспийска» к Telegram

## URL мини-приложения
https://kaspiysk-map.vercel.app/

Сайт уже содержит клиентскую интеграцию Telegram Mini Apps:
- загружает официальный Telegram Web App SDK при открытии внутри Telegram;
- вызывает `ready()` и `expand()`;
- подстраивает цвета шапки и фона под дизайн сайта;
- отслеживает изменение высоты WebView;
- сохраняет обычную работу сайта вне Telegram.

## Что нужно сделать владельцу Telegram-аккаунта

Telegram не позволяет внешнему сервису создать бота от имени пользователя без его действий в BotFather. Поэтому финальная привязка выполняется из аккаунта владельца:

1. Откройте https://t.me/BotFather
2. Отправьте `/newbot` и создайте бота «Открытый Каспийск». Сохраните токен у себя и никому его не отправляйте.
3. В BotFather выполните `/mybots`, выберите созданного бота.
4. Откройте **Bot Settings → Configure Mini App** (или **Main App / Enable Mini App**, если названия отличаются).
5. Укажите URL: `https://kaspiysk-map.vercel.app/` и сохраните.
6. Для кнопки запуска в чате откройте **Bot Settings → Menu Button → Configure menu button** (или выполните `/setmenubutton`), задайте текст «Открыть карту» и тот же URL.
7. При желании задайте описание бота через `/setdescription` и краткое описание через `/setabouttext`.

После сохранения пользователи смогут открыть сайт внутри Telegram из профиля/меню бота. Отдельный backend и токен бота не нужны, пока не требуются команды, уведомления или отправка данных от бота.

## Проверка
- Откройте бота в мобильном Telegram и нажмите кнопку запуска Mini App.
- Проверьте карту, формы и переходы между страницами.
- Проверьте сайт обычной ссылкой в браузере: Telegram-интеграция не должна менять его обычное поведение.


## Команды Telegram

Backend поддерживает команды для открытия отдельных страниц сайта. Каждая команда отвечает сообщением с отдельной кнопкой Mini App, ведущей прямо в нужный раздел:

- `/start` или `/help` — меню со всеми разделами.
- `/problem` — карта проблем города: `/problems.html`.
- `/outages` — отключения электроэнергии: `/outages.html`.
- `/trucks` — коммунальная техника: `/trucks.html`.
- `/procurements` — карта госзакупок: `/procurements.html`.
- `/weather` — погода: `/weather.html`.
- `/geography` — география города: `/geography.html`.
- `/about` — информация о проекте: `/about.html`.

Чтобы команды работали, в Render для API-сервиса `kaspiysk-map-1` должны быть заданы переменные окружения:

- `TELEGRAM_BOT_TOKEN` — токен бота из BotFather (секретный).
- `TELEGRAM_WEBHOOK_SECRET` — случайная строка из латинских букв и цифр длиной 32–64 символа.
- `TELEGRAM_WEBHOOK_URL` — `https://kaspiysk-map-1.onrender.com/telegram/webhook`.

После деплоя backend и перезапуска сервиса webhook автоматически регистрируется в Telegram, а сервер отправляет список команд через `setMyCommands`. Вручную добавлять команды через BotFather обычно не нужно. Не публикуйте токен и не вставляйте его в код или сообщения.

**Важно:** кнопка меню бота «Открыть карту», настроенная ранее в BotFather, по-прежнему открывает главную страницу сайта, потому что для неё задан URL `https://kaspiysk-map.vercel.app/`. Это отдельная кнопка, не команда. Для открытия конкретного раздела отправьте команду, например `/problem`, и нажмите появившуюся кнопку в ответе бота.

Если команда ничего не отвечает, проверьте наличие трёх переменных в Render и успешный деплой backend. Команды не создают обращение и не отправляют данные пользователя автоматически.
