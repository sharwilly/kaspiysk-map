# Реестр закупок для карты

Файл `procurements.json` — небольшой реестр записей, которые вручную проверены по первичным источникам. Он не требует отдельной таблицы в PostgreSQL.

## Как добавить закупку

Добавьте объект в массив `items` в `procurements.json`:

```json
{
  "id": "eis-уникальный-номер",
  "published": true,
  "title": "Предмет закупки из официального документа",
  "category": "building",
  "categoryLabel": "Строительство и ремонт",
  "status": "execution",
  "statusLabel": "Исполнение",
  "address": "Подтверждённый адрес объекта",
  "customer": "Заказчик по ЕИС",
  "purchaseNumber": "Номер извещения/закупки",
  "contractNumber": "Реестровый номер контракта",
  "price": 1234567,
  "startDate": "2026-01-01",
  "endDate": "2026-12-31",
  "latitude": 42.8913,
  "longitude": 47.6397,
  "locationVerified": false,
  "sourceName": "ЕИС «Закупки»",
  "sourceUrl": "https://zakupki.gov.ru/",
  "locationSourceName": "Картографический источник",
  "locationSourceUrl": "https://example.org/map-reference",
  "updatedAt": "2026-10-22",
  "notes": "При необходимости поясните ограничение данных."
}
```

## Правила публикации

- Не используйте придуманные названия, суммы, заказчиков или статусы.
- `sourceUrl` должен вести на первичный документ/карточку закупки, а не просто на главную страницу ЕИС.
- `published` должен быть `true`; иначе запись не попадёт в публичный API.
- Не ставьте координаты приблизительно «на глаз». Если точное место неизвестно, оставьте `latitude` и `longitude` равными `null`; запись останется в списке без маркера.
- Ставьте `locationVerified: true` только после проверки адреса и координат по документам или надёжному географическому источнику.
- `price` — число в рублях, без форматирования и разделителей. Если цена неизвестна, используйте `null`.
- Статусы и даты переносите из источника. Не обозначайте контракт как исполненный без подтверждения.

## API

Публичный read-only endpoint: `GET /procurements`.

Пока реестр пустой, API возвращает `items: []`. Это намеренно: реальные закупки не подменяются демоданными. Для проверки интерфейса можно открыть страницу с параметром `?demo=1`; демонстрационные записи там явно помечены.
